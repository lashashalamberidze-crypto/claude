# ღონისძიება — SPInTechSol × COMRAD (2026 წლის 25 სექტემბერი)

ერთობლივი პრეზენტაცია: **InTechSol** (SPInTechSol — საზედამხედველო ციფრული პლატფორმა) და
**Alait Limited** (COMRAD — პროფესიული კრიტიკული კომუნიკაციები / რაციები).

- **თარიღი:** 2026 წლის 25 სექტემბერი, პარასკევი (სექტემბრის ბოლო პარასკევი)
- **ადგილი:** თბილისი — [სასტუმროს დარბაზი, დასაზუსტებელი]
- **გამომსვლელები:** ლაშა შალამბერიძე (InTechSol) და Alait Limited-ის წარმომადგენელი
- **ფორმატი:** I ნაწილი — სახელმწიფო სექტორი · II ნაწილი — კერძო სექტორი (მშენებლობა, სასტუმროები) · B2B შეხვედრები (4 ჯგუფი)

Word-ში ჩასწორებას საჭიროებს კვადრატულ ფრჩხილებში მოცემული ველები:
- ლოკაცია / სასტუმროს დარბაზი
- Alait-ის წარმომადგენლის სახელი

## ხელახლა აგება

```bash
pip install python-docx
python3 build_docs.py
```

წყარო-ფაილები: `build_docs.py` (განლაგება/სტილი), `content_ge.py`, `content_ru.py` (ტექსტი).
