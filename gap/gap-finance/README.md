ეს სკრიპტები ტენდერის მონაცემებს პირდაპირ **GAP Finance-ის ბაზაში** ამატებს
(`Desktop\gap_finance\data\gap_finance.db`), იმავე სტრუქტურით, როგორც არსებული
პროექტები გაქვს.

## `add_zuzumbo_cnt260000076.py`

ამატებს ზუზუმბოს პარკის ტენდერს (ქ. თელავი, CNT260000076) სრული მონაცემებით
და 37 სამუშაოთი I / II / III ეტაპის მიხედვით.

### გაშვება

1. ჩააგდე ფაილი `Desktop\gap_finance\` საქაღალდეში (`start.bat`-ის გვერდით).
2. გახსენი PowerShell იმ საქაღალდეში და გაუშვი:

```powershell
cd "$env:USERPROFILE\Desktop\gap_finance"
.venv\Scripts\python.exe add_zuzumbo_cnt260000076.py
```

3. განაახლე `http://localhost:8000` — პროექტი სიაში გამოჩნდება.
