# GAP — ინფორმაციის ბაზა (დესკტოპზე)

მთელი ინფორმაცია ერთ ადგილას, **სერვერის და Python-ის გარეშე**.
უბრალოდ გახსენი `gap-info.html` — და ყველა ცვლილება ავტომატურად ინახება.

---

## 1. როგორ დავაყენო დესკტოპზე (ერთხელ)

1. გადმოწერე ეს საქაღალდე (`gap`) კომპიუტერზე.
2. ორმაგი დაწკაპუნება **`Desktop-Setup.bat`** — თავად გადაიწერს დესკტოპზე
   (`Desktop\GAP\`) და გახსნის.
   *(ან უბრალოდ ხელით გადმოაგდე საქაღალდე დესკტოპზე.)*
3. მერე ყოველდღე ხსნი: **`GAP-Info.bat`** ან პირდაპირ `gap-info.html`.

> სურვილისამებრ: მარჯვენა ღილაკი `gap-info.html`-ზე → *Send to → Desktop
> (create shortcut)* — და დესკტოპზე ერთი ხატულა გექნება.

---

## 2. როგორ ინახება ინფორმაცია

ორ ადგილას ერთდროულად:

| სად | როგორ | რას აკეთებ |
|-----|-------|------------|
| **ბრაუზერში** | ავტომატურად, ყოველი ცვლილებისას | არაფერს — თავისით მუშაობს |
| **დესკტოპის ფაილში** `gap-info-data.json` | ავტომატურად, თუ ერთხელ დააკავშირებ | დააჭირე **📁 ფაილთან დაკავშირება** → აირჩიე დესკტოპი → Save |

**ერთხელ დააკავშირე და დაივიწყე** — შემდეგ ყოველი ცვლილება იმავე წამს ჩაიწერება
`gap-info-data.json`-ში. თუ ბრაუზერი გაასუფთავებ ან კომპიუტერს გამოცვლი,
ეს ფაილი შენი სრული სარეზერვო ასლია.

- **📁 ფაილთან დაკავშირება** მუშაობს Chrome-სა და Edge-ში.
- სხვა ბრაუზერში გამოიყენე **💾 ჩამოტვირთვა** (ინახავს `gap-info-data.json`-ს)
  და **📂 ჩატვირთვა** (აბრუნებს უკან).
- ზედა ზოლი ყოველთვის გიჩვენებს სად ინახება და როდის შეიცვალა ბოლოს.

---

## 3. როგორ დავამატო ინფორმაცია

1. დააჭირე **`+ დამატება`**.
2. აირჩიე **კატეგორია**: ტენდერი · პროექტი · კომპანია · კონტაქტი · აპლიკაცია · სხვა.
3. შეავსე **სათაური** (სავალდებულო), ქვესათაური, სტატუსი, **ვადა**.
4. **დეტალები** — რამდენიც გინდა წყვილი „სახელი → მნიშვნელობა“
   (მაგ. `სავარაუდო ღირებულება` → `850 000 ₾`). `+ ველის დამატება` ამატებს ახალ სტრიქონს.
5. **ბმულები** — სამი სახე:
   - გარე ბმული: `https://…`
   - ადგილობრივი ფაილი: `docs/სახელი.pdf` (PDF-ს ჩააგდებ `docs/`-ში) — მუშაობს
     მხოლოდ მაშინ, თუ `docs/` საქაღალდე `gap-info.html`-ის გვერდითაა
   - **ჩაშენებული დოკუმენტი:** `asset:გასაღები` — PDF თვითონ HTML ფაილშია ჩაწერილი,
     ამიტომ ერთი დაწკაპუნებით იხსნება ყოველთვის, საქაღალდის გარეშეც
6. **შენახვა** — მაშინვე ჩაიწერება.

რედაქტირება: გახსენი ჩანაწერი → **✏️ რედაქტირება**.
წაშლა: იმავე ფანჯარაში → **წაშლა**.

### ვადები
თუ „ვადა“ შეავსებ, ბარათზე ავტომატურად გამოჩნდება მრიცხველი:
🟢 ჯერ დროა · 🟡 7 დღეზე ნაკლები · 🔴 ვადა გავიდა.

### სხვა ღილაკები
| ღილაკი | რას აკეთებს |
|--------|-------------|
| ძებნა | ეძებს ყველა ტექსტში — სათაურში, დეტალებში, შენიშვნებში |
| 📋 ტექსტად კოპირება | ჩანაწერს აკოპირებს, რომ ელფოსტაში ან Word-ში ჩასვა |
| 🖨 | ბეჭდვა / PDF-ად შენახვა (ყველა ჩანაწერი გაშლილი) |
| 🌓 | ღია / მუქი თემა |

## 5. საქაღალდის შიგთავსი

```
gap/
├─ gap-info.html        ← ინფორმაციის ბაზა (მთავარი ფაილი; ტენდერის PDF შიგნითაა)
├─ GAP-Info.bat         ← გახსნის ბაზას
├─ Desktop-Setup.bat    ← ერთხელ: დააკოპირებს დესკტოპზე
├─ index.html           ← GAP Group-ის ვებგვერდი (KA/EN/RU)
├─ GAP_Finance.bat      ← ძველი ლოკალური აპლიკაციის გამშვები (Python-ს საჭიროებს)
└─ docs/
   └─ zuzumbo-park-telavi-tenderi.pdf
```

`gap-info-data.json` შენს დესკტოპზე შეიქმნება, როცა „📁 ფაილთან დაკავშირებას“ დააჭერ.

## 6. ახალი PDF-ის ჩაშენება (თუ დაგჭირდება)

ტენდერის PDF უკვე ჩაშენებულია. თუ სხვა დოკუმენტსაც იმავენაირად გინდა:

- **მარტივი გზა:** ჩააგდე PDF `docs/` საქაღალდეში და ბმულში დაწერე `docs/სახელი.pdf`.
  (მუშაობს, სანამ საქაღალდეს მთლიანად ინახავ.)
- **ჩაშენება:** მთხოვე — `gap-info.html`-ის `ASSETS` ობიექტში დაემატება ახალი გასაღები
  (`name` / `type` / `b64`), ბმულში კი დაიწერება `asset:ახალი-გასაღები`.
