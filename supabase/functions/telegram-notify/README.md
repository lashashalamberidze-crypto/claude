# Telegram შეტყობინება — გამართვის ინსტრუქცია

როცა ინვოისის სტატუსი გახდება **„გადახდილი"** (💵 სრული გადახდა), ადმინ-პანელი
ამ Edge Function-ს გამოიძახებს და ტელეგრამზე გამოგზავნის: ინვოისის დეტალს +
საერთო გაყიდვების ანალიტიკას მიმართულებების მიხედვით.

ბოტის **ტოკენი აქ ინახება სერვერზე (secret) — საიტის კოდში არ ჩანს.**

## 1. ბოტის შექმნა
1. ტელეგრამში დაწერე **@BotFather** → `/newbot` → მიჰყევი ინსტრუქციას.
2. მიიღებ **ტოკენს**: მაგ. `8123456789:AAH...` — შეინახე.

## 2. Chat ID-ის გაგება
- **პირადი ჩატი:** დაწერე შენს ბოტს რამე (მაგ. „hi"), მერე გახსენი:
  `https://api.telegram.org/bot<ТОКEN>/getUpdates` — იპოვე `"chat":{"id":123456789}`.
- **ჯგუფი:** დაამატე ბოტი ჯგუფში, დაწერე ჯგუფში რამე, იგივე `getUpdates` —
  ჯგუფის id უარყოფითია (მაგ. `-1001234567890`).

## 3. Function-ის დაყენება (ერთხელ)
Supabase CLI-ით (პროექტი: `mhyoqypzacvztwhntsvv`):

```bash
supabase login
supabase link --project-ref mhyoqypzacvztwhntsvv
supabase functions deploy telegram-notify
supabase secrets set TELEGRAM_BOT_TOKEN=8123456789:AAH... TELEGRAM_CHAT_ID=123456789
```

> თუ გამოძახებაზე 401 მოვა, თავიდან დააფდაუნე `--no-verify-jwt`-ით:
> `supabase functions deploy telegram-notify --no-verify-jwt`
> (ადმინი ისედაც ავტორიზებულია, ამიტომ ჩვეულებრივ საჭირო არ არის.)

## 4. ტესტი
ინვოისს დაუყენე სტატუსი „გადახდილი" (💵) → ტელეგრამზე უნდა მოვიდეს მესიჯი.
თუ არ მოვა — ბრაუზერის Console-ში ნახე `telegram notify` შეცდომა.
